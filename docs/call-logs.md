# 调用日志

从模块设置的“调用日志 → 查看调用日志”进入。日志默认开启，只保留最近 200 条，支持刷新、失败筛选、复制当前筛选结果和确认后清空。页面在前台时每两秒刷新；退出页面即停止轮询。

日志开关立即作用于新记录，不需要重启 Aicy；关闭时保留历史，已经记录的请求仍可更新结束状态。清空日志不改变 API 配置，正在执行的请求结束时不会重新插回已清除记录。升级模块 APK 后仍需重新启动 Aicy，让新 Hook 生效。

## 记录范围

| 内容 | 含义 |
| --- | --- |
| 时间、来源、阶段 | Aicy HTTP 请求、连接测试，或客户端/模块初始化诊断 |
| 模型与域名 | 保存的模型 ID 和服务商域名；域名不包含 URL 路径、查询参数、片段或用户信息 |
| HTTP 状态 | Aicy 独立 HTTP 客户端实际收到的响应码，包含限流、鉴权失败和不跟随的重定向 |
| 耗时 | Aicy 请求从进入 HTTP 拦截器到收到响应头；连接测试统计完整请求 |
| 错误 | 固定的网络、超时、TLS、协议、凭据、兼容性或取消类别 |

Aicy 的“已收到响应 / HTTP 200”表示响应头已到达，后续流式输出和 Agent 任务可能继续运行；不记录其完成状态或输出。连接测试验证完整的非流式消息，显示“测试成功”；底层客户端未暴露成功状态码时显示为“—”，不伪造 HTTP 200。

不记录 API Key、请求/响应头、完整 URL、对话正文、工具参数、响应正文、服务商原始错误或异常消息。已知 API Key 在模型和域名字段中也会先被替换，再进行长度限制；导出使用相同的固定字段。日志不包含 Token 用量或计费数据。

## 保存与访问

日志独立保存在模块私有 SQLite 数据库，继承应用禁止备份的设置。配置不存入日志库。已有 Provider 对 Aicy 的包名、UID 和签名检查同样适用于追加和完成记录；读取、复制、开关与清空由未导出的模块日志页面完成，没有新增外部读取日志接口。

Aicy 进程通过容量为 128 的队列异步写入，空闲工作线程在 30 秒后回收，没有增加常驻服务或后台锁定要求。记录为尽力保存：进程退出、队列拥塞或 Provider 不可用时可能缺少记录或结束状态。日志写入错误不改变模型请求的结果或异常。

## HTTP 接入

日志拦截器只安装到模块创建的独立 OkHttp 客户端，不触碰官方共享客户端、其他工具的 HTTP 请求、请求体或响应流。

目标 `bi.N` 接口缺少检查异常声明，Java Proxy 会把原始 IOException 包装为 UndeclaredThrowableException。为保留网络错误和取消语义，模块通过 InMemoryDexClassLoader 加载一个自有的 1008 字节拦截器类，直接转发到 InvocationHandler。它只引用目标接口描述符，没有厂商实现、接口 Stub 或第三方运行库。日志接口不可用时显示诊断记录，原请求继续运行。

该类的生成器为 `tools/generate_log_bridge.py`，只使用 Python 标准库、项目要求的 Android SDK 和官方 D8；生成后的 Java 包装代码随源码提交，普通构建不需要额外生成步骤。

```sh
python3 tools/generate_log_bridge.py --sdk "$ANDROID_HOME"
python3 tools/verify_target_apk.py 原始Aicy.apk
python3 tools/verify_module_apk.py 模块.apk
```

打包核对会检查嵌入 DEX 的校验和、唯一自有类、目标接口、方法签名，以及无异常包装的转发结构。设备上的框架、类加载和实际网络行为仍需真机验证。
