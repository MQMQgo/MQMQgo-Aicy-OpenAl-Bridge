# 调用日志

从模块底部悬浮胶囊的日志图标进入，主页保留渠道、连接测试和运行状态。日志默认开启，只保留最近 200 条，支持全部/成功/失败筛选、成功与失败计数、刷新、复制当前筛选结果和确认后清空。切换页面会保留筛选和滚动位置；日志页按系统返回键回到主页。日志页在前台时每两秒刷新，切回主页或退到后台即停止轮询。

日志开关立即作用于新记录，不需要重启 Aicy；关闭时保留历史，已经记录的请求仍可更新结束状态。清空日志不改变 API 配置，正在执行的请求结束时不会重新插回已清除记录。升级模块 APK 后仍需重新启动 Aicy，让新 Hook 生效。

## 记录范围

| 内容 | 含义 |
| --- | --- |
| 时间、来源、阶段 | Aicy HTTP 请求、连接测试、模型列表，或客户端/模块初始化诊断 |
| 模型与域名 | 保存的模型 ID 和服务商域名；域名不包含 URL 路径、查询参数、片段或用户信息 |
| HTTP 状态 | Aicy 独立 HTTP 客户端实际收到的响应码，包含限流、鉴权失败和不跟随的重定向 |
| 耗时 | Aicy 请求从进入 HTTP 拦截器到收到响应头；连接测试统计完整请求 |
| 错误 | 固定的网络、超时、TLS、协议、凭据、兼容性或取消类别 |

Aicy 的“已收到响应 / HTTP 200”表示响应头已到达，后续流式输出和 Agent 任务可能继续运行；不记录其完成状态或输出。“成功”筛选包含 HTTP 2xx，以及模块完整连接测试或模型列表获取成功，不代表 Agent 任务完成。连接测试和模型列表保留实际响应状态码；历史未记录状态码的条目显示“—”。无法读取原生响应码时，结束为“已收到响应（状态未知）”，不计入成功，不伪造 HTTP 200。

不记录 API Key、请求/响应头、完整 URL、对话正文、工具参数、响应正文、服务商原始错误或异常消息。已知 API Key 在模型和域名字段中也会先被替换，再进行长度限制；导出使用相同的固定字段。日志不包含 Token 用量或计费数据。

## 保存与访问

日志独立保存在模块私有 SQLite 数据库，继承应用禁止备份的设置。配置不存入日志库。已有 Provider 对 Aicy 的包名、UID 和签名检查同样适用于追加和完成记录；读取、复制、开关与清空在模块设置内的日志页完成，没有新增外部读取日志接口。

数据库首次打开在进程内串行化，建表与元数据初始化保持幂等，避免后台上报和日志页同时首次打开时重复建表。初始化不会清除已有记录或重置“清空之前”的时间标记。

Aicy 进程通过容量为 128 的队列异步写入，空闲工作线程在 30 秒后回收，没有增加常驻服务或后台锁定要求。记录为尽力保存：进程退出、队列拥塞或 Provider 不可用时可能缺少记录或结束状态。日志写入错误不改变模型请求的结果或异常。

## HTTP 接入

v0.4.1 撤销 v0.4.0 的全局 RealCall Hook，日志仅在模块创建的独立 OkHttp 客户端中挂载。不会在应用启动时对共享 OkHttp 执行方法注册全局 Hook。

使用一个模块自有的 1008 字节具体拦截器，通过 InMemoryDexClassLoader 加载，直接转发 InvocationHandler，避免 Java Proxy 包装原始检查异常。该类只引用目标接口描述符，没有厂商实现或接口 Stub。模块不读取请求体、请求头或响应流；返回原响应实例，并原样抛出原异常。挂载失败记录兼容诊断，模型请求继续使用原有传输。

模型列表、成功筛选、真实 HTTP 状态与数据库并发初始化修复保留。无法读取状态码时仍记录为未知，不冒充成功。

```sh
python3 tools/generate_log_bridge.py --sdk "$ANDROID_HOME"
python3 tools/verify_target_apk.py 原始Aicy.apk
python3 tools/verify_module_apk.py 模块.apk
```

原 APK 静态核对包含独立客户端构造、原生拦截器接口、请求链、取消状态和响应码字段。打包检查确认只包含一个模块自有桥接类，并核对校验和及无异常包装的转发结构。生成器 JVM 测试执行字节码，验证响应与检查异常实例保留。设备上的框架和实际网络行为仍需真机验证；升级后必须重新启动 Aicy。
