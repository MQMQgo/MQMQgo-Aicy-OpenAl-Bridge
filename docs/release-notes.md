# Aicy OpenAI Bridge 0.1.0

首个 API102 测试版本，适配 Aicy 13.1.1（13001001）。

- 可安装的签名 APK，含 HTTPS API 地址、模型、密钥及连接测试设置。
- 复用 Aicy 原生对话、流式响应和本地 Agent，替换模型请求的端点与凭据。
- 清理魅族专用请求参数，隔离原生 HTTP 鉴权，并关闭自动重定向。
- 使用本地工具元数据发现，保留原有动作确认与验证。

要求支持现代 libxposed API102 的框架。安装后启用作用域 Aicy，填写并保存配置，再强行停止并重新打开 Aicy。

16 项协议测试通过；原 APK 中 20 个类的反射 ABI 核对通过；APK 构建、lint、模块打包、v2/v3 签名及 zipalign 检查通过。尚未在真实 Flyme 手机和 API102 框架上运行验证。

模型需支持工具调用；图片任务还需视觉能力。联网、图片生成及远程工具仍各自依赖服务与授权。安装 `aicy-openai-bridge-v0.1.0-api102.apk`；开发用调试 APK 的签名与发布包不同，不应互相覆盖安装。
