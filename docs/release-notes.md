# Aicy OpenAI Bridge 0.3.1

新增居中的 Miuix 悬浮胶囊底栏，分为主页和日志两页。主页保留渠道、连接测试与运行状态；日志记录、筛选、复制、清空和记录开关移到独立页面。

切换页面保留未保存的 API 草稿、各页滚动位置与日志筛选。输入法显示时收起底栏，日志页按系统返回键回到主页。浅色与深色模式均适用。

安装 `aicy-openai-bridge-v0.3.1-api102.apk`，与旧版同签名，可覆盖安装并保留数据。保存的配置、日志与启动修复沿用 v0.3.0。

## 0.3.0

新增调用日志页面，记录 Aicy 模型请求和模块连接测试的时间、模型、服务商域名、HTTP 状态、耗时及固定错误类别。支持失败筛选、复制、刷新、清空和记录开关，保留最近 200 条。

不记录 API Key、完整 URL、请求/响应正文、对话、工具参数或原始错误。Aicy 的流式记录统计到响应头到达；连接测试统计完整请求。异步日志写入不改变原请求结果和异常。保留 v0.2.1 的启动资料隔离修复与现有配置。

安装 `aicy-openai-bridge-v0.3.0-api102.apk`，同签名覆盖安装并重新启动 Aicy。日志开关立即作用于新记录。具体范围见 [调用日志](call-logs.md)。

## 0.2.1

修复启用自定义模型后 Aicy 启动闪退。旧版把自定义模型名用于内部媒体限额查询，导致未知模型触发 IllegalStateException，进而使工具和页面初始化失败。

现在启动和工具初始化保留原生模型资料，仅在同步创建实际 LLM 客户端时替换接口配置。自定义模型仍用于第三方 API 请求；范围在异常和嵌套调用结束后恢复，并与其他线程隔离。保持 API102、Miuix 界面和现有渠道存储。

安装 `aicy-openai-bridge-v0.2.1-api102.apk`，与旧版同签名，可覆盖安装。若 Aicy 当前无法启动，先关闭模块或第三方模型开关，安装后重新启用并强行停止、重开 Aicy。请保留模块数据。

## 0.2.0

设置界面改用 Miuix 0.9.4，支持浅色、深色模式，分组显示渠道、连接测试和运行状态。

- 保存成功后展示“我的渠道”；退出重开重新读取已提交的配置。
- 关闭接管保留 API 地址、模型和加密密钥；启用开关与渠道保存独立。
- 兼容 v0.1.0 的存储记录。系统暂时无法解密时保留渠道，支持重试读取；编辑时 Key 留空保留原密文。
- 使用相同发布证书，可直接覆盖安装本仓库 v0.1.0 发布包。不要先卸载或清除应用数据。

安装 `aicy-openai-bridge-v0.2.0-api102.apk`。仍要求现代 libxposed API102，仍适配 Aicy 13.1.1（13001001）。保存或切换接管后请强行停止并重新打开 Aicy。

配置恢复与 Compose 界面使用 Robolectric 做回归验证，包含关闭页面后重新启动 Activity；实际 Flyme、硬件 Keystore 与 LSPosed 仍需设备验证。具体测试及 APK 校验结果见 [VALIDATION.md](../VALIDATION.md)。

## 0.1.0

首个 API102 测试版本，适配 Aicy 13.1.1（13001001）。

- 可安装的签名 APK，含 HTTPS API 地址、模型、密钥及连接测试设置。
- 复用 Aicy 原生对话、流式响应和本地 Agent，替换模型请求的端点与凭据。
- 清理魅族专用请求参数，隔离原生 HTTP 鉴权，并关闭自动重定向。
- 使用本地工具元数据发现，保留原有动作确认与验证。

要求支持现代 libxposed API102 的框架。安装后启用作用域 Aicy，填写并保存配置，再强行停止并重新打开 Aicy。

16 项协议测试通过；原 APK 中 20 个类的反射 ABI 核对通过；APK 构建、lint、模块打包、v2/v3 签名及 zipalign 检查通过。尚未在真实 Flyme 手机和 API102 框架上运行验证。

模型需支持工具调用；图片任务还需视觉能力。联网、图片生成及远程工具仍各自依赖服务与授权。安装 `aicy-openai-bridge-v0.1.0-api102.apk`；开发用调试 APK 的签名与发布包不同，不应互相覆盖安装。
